# Joshua Day, PhD

My name is Josh. I'm a generalist that's worked with a ton of different domains.  If my specialty is anything it's translating whiteboard math into fast, usable software. [Julia](https://julialang.org) is my language of choice, and every project I build is driven by two priorities: performance and usability.

## Current Projects

I lead software engineering at [RallypointOne](https://github.com/RallypointOne), building Julia-based simulation and hybrid physics/ML models for federal R&D:

<p align="center"><img src="https://raw.githubusercontent.com/RallypointOne/website-assets/main/rp1-email-signature-2026.png" height="80"/></p>

- **[ARID](https://rallypoint1.com)** (NSF ASCEND Engine): Asset Resilience through Intelligent Digital Twins — systems integration and translation across a portfolio of researchers, startups, utilities, and government partners working on wildfire/water/power resilience in the Colorado–Wyoming region. Continues the wildfire digital-twin work started under **HEATMAPS**: GPU-accelerated simulation and continuous surrogate environment fields for fire decision support.
- **[MICROCAST](https://rallypoint1.com)** (Navy SBIR): Hybrid forecasting framework for naval operations integrating [SpeedyWeather](https://github.com/SpeedyWeather/SpeedyWeather.jl), [Oceananigans](https://github.com/CliMA/Oceananigans.jl), [Breeze](https://github.com/NumericalEarth/Breeze.jl), [NumericalEarth](https://github.com/NumericalEarth/NumericalEarth.jl), as well as numerical weather prediction tools from outside the Julia ecosystem.
- **IRAM** (NASA SBIR Ignite): Real-time hybrid physics/ML modeling of metal additive manufacturing — universal differential equations updated live from sensor data for defect prediction and closed-loop control.
- **MIHSO** (Metis Foundation): A multiscale cardiac digital twin for hemorrhagic shock and ischemia–reperfusion, built on the Julia [SciML](https://sciml.ai) stack — coupling cell-scale electrophysiology, contraction, and mitochondrial energetics up to whole-heart simulation.
- **ITCF** (Navy STTR, with Colorado State): Integrated Tropical Cyclone Forecasting Suite — modernizing the Navy's legacy ATCF into a database-backed, API-driven architecture while preserving deck-file compatibility.

## Things I've Built

### Statistics & Data

- [**OnlineStats.jl**](https://github.com/joshday/OnlineStats.jl): Single-pass algorithms for statistics and data viz with big data.
- [**AverageShiftedHistograms.jl**](https://github.com/joshday/AverageShiftedHistograms.jl): Lightning-fast density estimation in Julia.

### Web & Markup

- [**PlotlyLight.jl**](https://github.com/JuliaComputing/PlotlyLight.jl): Lightweight, easy-to-use wrapper of the fantastic [Plotly.js](https://plotly.com/javascript/) plotting library.
- [**XML.jl**](https://github.com/JuliaData/XML.jl): An XML reader/writer in pure Julia that performs comparably to implementations in C.
- [**Cobweb.jl**](https://github.com/JuliaComputing/Cobweb.jl): An HTML reader/writer in pure Julia that's fast and easy to use.

### Geospatial & Simulation

- [**Wildfires.jl**](https://github.com/RallypointOne/Wildfires.jl): Wildfire modeling and simulation in Julia.
- [**Elmfire.jl**](https://github.com/RallypointOne/Elmfire.jl): Julia implementation of the ELMFIRE fire propagation model.
- [**GeoSurrogates.jl**](https://github.com/RallypointOne/GeoSurrogates.jl): Surrogate function representations of geospatial data.
- [**WildfireData.jl**](https://github.com/RallypointOne/WildfireData.jl): Unified Julia interface for federal wildfire data (LANDFIRE, NIFC, GOES-16, HRRR).

### Tools & Utilities

- [**DepotDelivery.jl**](https://github.com/JuliaComputing/DepotDelivery.jl): Create a standalone Julia depot for air-gapped deployments.
- [**Terse.jl**](https://github.com/RallypointOne/Terse.jl): Shorthand for defining full type hierarchies.
- [**TokenIterators.jl**](https://github.com/joshday/TokenIterators.jl): Fast framework for writing lexers/tokenizers.
- [**XKCD.jl**](https://github.com/joshday/XKCD.jl): Retrieve image and metadata from the XKCD webcomic.

### Apps

- [**One Click Tuner**](https://oneclicktuner.com): iOS app with a chromatic musical instrument tuner.
